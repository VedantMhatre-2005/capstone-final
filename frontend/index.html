System Architecture

Three-Phase Closed-Loop Pipeline

Each phase feeds directly into the next, forming a continuously self-improving quantum-classical control loop for real-time urban traffic management.

🕸️ Traffic Network Graph Modeling  ·  G = (V, E)
Network Abstraction

Before entering the three computational stages, the urban road network is mathematically modeled as a directed spatial graph \( G = (V, E) \) where physical infrastructure and traffic dynamics are mapped directly to graph topology:

Graph Representation: G = (V, E)

STQGCN — Spatio-Temporal Quantum Graph Convolutional Network

A graph neural network operating on the road network topology, capturing both spatial (cross-junction) and temporal (time-series) dependencies in vehicle flow, then routing node representations through a Variational Quantum Circuit (VQC) for quantum-enhanced feature encoding.

QAOA — Quantum Approximate Optimisation Algorithm

Congestion levels predicted by STQGCN are encoded into a QUBO Hamiltonian. QAOA, running on Qiskit's StatevectorSampler with COBYLA, finds the near-optimal binary routing assignment for diverting excess traffic onto underutilised alternate paths.

Closed-Loop Feedback — Optimised State Re-enters Prediction

QAOA's optimised traffic flows become the new observed state feeding back into STQGCN at the next prediction cycle. The model forecasts from a quantum-optimised ground truth, progressively steering the network toward congestion-free equilibrium.

Quantum Architecture

Variational Quantum Circuit (VQC) inside STQGCN

The 8-qubit VQC is the quantum heart of STQGCN. Node embeddings are angle-encoded via RY gates, evolved through K variational layers with CNOT ring entanglement, and measured as Pauli-Z expectation values.
